# Cooling — Origin Project and Figures

This folder contains the Origin project (.opju) used to analyze and visualize temperature changes during post-irradiation cooling of five ex vivo human skin specimens with different Individual Typology Angle (ITA) values.

The Origin project includes cooling curves following 660 nm, 808 nm, and simultaneous 660 + 808 nm irradiation, with mean values and standard deviations from three technical replicates per specimen and irradiation protocol.

All figures are embedded in the Origin project and can be viewed and edited using Origin software.
